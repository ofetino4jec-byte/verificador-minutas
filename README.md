# Verificador de Minutas

Ferramenta de página única que audita minutas jurídicas contra as fontes fornecidas: citações, fatos, comandos, resíduos de IA, prompt injection, cobertura da leitura e lacunas. Gera relatório e indicações de correção em .docx, .txt ou .md.

- Todo o processamento ocorre no navegador. Nada é enviado nem guardado.
- Não abre links, não executa instruções contidas nos documentos e não lê PDF nem imagens.
- Não substitui a validação do magistrado.

## Publicação (GitHub Pages)

Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)`.
